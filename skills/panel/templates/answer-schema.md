## VERDICT
One or two sentences. Your bottom-line answer to every charter question (Q1, Q2, …).

## KEY CLAIMS
Numbered, one per line, each independently checkable. Format exactly:
C1. <claim>
C2. <claim>

## REASONING
How you got from evidence to claims. Cite absolute paths / line numbers / commands when the charter points at code or docs.

## RISKS
Failure modes, downsides, what would make you wrong.

## ASSUMPTIONS
What you took as given. Mark anything you could not verify.

## CONFIDENCE
A single integer 0-100 on the first line, then one sentence why.

## OPEN QUESTIONS
What you would need to know to be more certain. Write "none" if none.

## CORRECTIONS
Optional. Factual errors you found in the record (a wiki page, a file) that should be fixed regardless of the verdict. One per line, `path: what is wrong → what is right`. Write "none" if none.
